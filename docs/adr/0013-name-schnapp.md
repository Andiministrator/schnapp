# ADR-0013: Name „Schnapp"

## Status
Akzeptiert (Andi, 18.11.2026; übernommen am 19.11.2026)

## Kontext
Das Werkzeug braucht einen kurzen, deutschen, gut tippbaren Namen.

## Entscheidung
Name **Schnapp**, Befehl `schnapp`. Eine kurze Suche am 18.11.2026 ergab kein gleichnamiges Werkzeug.

## Konsequenzen
- Vor der Veröffentlichung auf Flathub und in Paketquellen den Namen erneut prüfen (E-08). Fällt die Prüfung
  negativ aus, wird umbenannt, bevor etwas öffentlich ist.
- Flatpak-ID z. B. `io.github.andiministrator.Schnapp`.
