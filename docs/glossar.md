# Glossar

## Produktbegriffe

| Begriff | Bedeutung |
|---|---|
| **Aufnahme** | Ein Screenshot (Bereich, Fenster, Bildschirm). Landet sofort in der Bibliothek. |
| **Aufnahmeschicht** | Austauschbare Schnittstelle, über die Schnapp Aufnahmen holt (KWin, später Portal). ADR-0007. |
| **Overlay** | Vollbildfenster über allen Monitoren zur Bereichsauswahl, mit Lupe, Pixelraster und Maßanzeige. |
| **Bibliothek** | Automatische Sammlung aller Aufnahmen mit Vorschau, Datum, Quellprogramm, Suche, Schlagworten. |
| **Leiste der letzten Aufnahmen** | Englisch „Recent captures“, bei Snagit „Tray“. Leiste unter dem Bild im Editor mit den Vorschaubildern der neuesten Aufnahmen (neueste links, offene grün, ohne Agenten-Aufnahmen); ein Klick öffnet eine im selben Fenster, nachdem die offene gespeichert ist (**Wechsel**); unter jeder Vorschau Zeit und Auflösung, ✕ (Zeiger oder langer Druck) bzw. Entf legt in den Papierkorb. Ansicht → „Letzte Aufnahmen“, Strg+Umschalt+R, `[library] bar`. ADR-0036, `internal/ui/leiste_unten.go`, Logik `internal/libview`. |
| **Markierung** | Englisch „selection“ (Oberfläche: „N captures selected“). Mehrere Vorschauen der Leiste der letzten Aufnahmen oder der vollen Ansicht, die zusammen in den Papierkorb gehen oder im Dateimanager gezeigt werden: Strg/Umschalt+Klick, Strg+Leertaste, Umschalt+Pfeile, Strg+A, Esc hebt auf; orange getönt mit Haken. Je eine in Leiste und Ansicht, nur für Gezeigtes. Nicht: die **Auswahl** (das gewählte Objekt auf der Leinwand mit Griffen, `canvas.Sitzung.Auswahl`). ADR-0036 Zusatz Karte #361, `libview.Markierung`, `internal/ui/markierung.go`. |
| **Mehrfachauswahl** | Mehrere gewählte Beschriftungen auf der Leinwand (Oberfläche: „N objects selected“): Umschalt+Klick, Auswahlrahmen (Ziehen auf freier Fläche im Bild, gewählt ist, was ganz darin liegt), Strg+A. Gemeinsam verschieben, löschen, doppeln, ausrichten, verteilen, je ein Rückgängig-Schritt. Eine davon ist die **Hauptauswahl**. Nicht: die **Markierung** (Vorschauen der Bibliothek). ADR-0039, `internal/canvas/mehrfach.go`. |
| **Hauptauswahl** | Die zuletzt gewählte Beschriftung einer Mehrfachauswahl (`canvas.Sitzung.Auswahl`): Nur sie trägt Griffe, auf sie wirken rechte Leiste, Farbe, Schnellstile, Texteingabe und die übrigen Ebenen-Handlungen; die weiteren gewählten (`Sitzung.Gewaehlt` ohne sie) zeigen nur einen Rahmen. ADR-0039 Punkte 1 und 4. |
| **Gruppe** | Mehrere Beschriftungen, die zusammen gewählt werden (Strg+G, Aufheben Strg+Umschalt+G): flach, eine Kennung `document.Ebene.Gruppe` an jedem Mitglied, wirksam ab zwei Mitgliedern; ein Klick auf ein Mitglied wählt alle, die Ebenenliste wählt zeilenweise. Nicht: eine Ebenengruppe mit Kindern. ADR-0044, `internal/canvas/gruppe.go`. |
| **Gemischt** | Anzeige der rechten Leiste, wenn mehrere gewählte Objekte einen Wert verschieden tragen („Mixed“, geteiltes Farbfeld, Kästchen mit Strich). ADR-0039 Nachtrag 4 Punkt 4. |
| **Volle Ansicht der Bibliothek** | Englisch „Library“. Die ganze Bibliothek im Editorfenster statt Werkzeugleiste, Leinwand und Leisten (Menüzeile und Fußzeile bleiben): Raster nach Monaten, Suche nach Schlagwort, Zeitraum, Schalter für Agenten-Aufnahmen; Enter/Doppelklick öffnet (**Wechsel**), Entf oder ✕ legt in den Papierkorb, F2 bearbeitet Schlagworte. Datei → „Bibliothek“, Strg+Umschalt+L, Knopf in der Leiste. ADR-0036 Punkte 3 und 4, `internal/ui/bibliothek.go`, Logik `internal/libview/raster.go`. |
| **Arbeitsdatei** | PNG mit eingebettetem SVG-Block (ADR-0008). Überall ein Bild, in Schnapp voll bearbeitbar. |
| **SVG-Block** | Privater PNG-Chunk mit dem vollständigen SVG: Ebenen, Original, Stauch- und Zuschnittangaben. |
| **Original** | Die unbeschnittene, ungestauchte Aufnahme in der Arbeitsdatei. Wird nur durch Schwärzen verändert. |
| **Pixelebene** | Die Aufnahme als Bild im Ebenenmodell. |
| **Vektorebene** | Eine Beschriftung (Pfeil, Kasten, Text …) als SVG-Element. |
| **Ebene** | Jede Beschriftung ist eine Ebene über dem Bild, mit Name, Sichtbarkeit, Sperre und Deckkraft; das Bild ist die unterste, Schwärzungen gehören zu ihm. Ausgeblendete Ebenen fehlen in Export und Zwischenablage, bleiben aber in der Arbeitsdatei (kein Schwärzen). Leiste „Ebenen“ und Menü „Ebene“, ADR-0032. |
| **Schwärzen** | Bereich deckend überdecken; überschreibt die Pixel auch im Original. Endgültig. |
| **Verpixeln** | Bereich grob aufrastern; überschreibt ebenfalls das Original. |
| **Stauchen** | Aus der Mitte eines Bildes einen Streifen ausblenden (Header und Footer bleiben), nicht zerstörend, mit Kante an der Naht (Kantenform). Snagit: „Cut Out". |
| **Stauchnaht** | Die Stelle, an der gestaucht wird; Schnapp kann eine vorschlagen (Bildvergleich). |
| **Zackenkante** | Gezackter Rand an einer Stauchnaht oder Bildkante, zeigt „hier fehlt etwas"; heute eine der drei Kantenformen (`zigzag`). |
| **Kontextmenü** | Liste auf Rechtsklick (oder Umschalt+F10) mit den Handlungen für das Ziel unter dem Zeiger: Objekt der Leinwand oder Bild; läuft über die Menü-Mechanik als `listeKontext` (`internal/ui/kontext.go`, Wahl über `canvas.KontextBei`). An Vorschauen der Leiste und der vollen Ansicht der Bibliothek (Teil 2): Öffnen, Im Dateimanager zeigen (`org.freedesktop.FileManager1`), Schlagworte, Papierkorb (`internal/ui/kontext_vorschau.go`). ADR-0038. |
| **Kantenform** | Form der Kante an Stauch-Nähten, je Dokument: Abriss (`tear`, Voreinstellung), Welle (`wave`), Zacken (`zigzag`); dazwischen ein durchsichtiger Spalt, die Kanten als Papier-Abriss angedeutet. Einstellung `[capture] seam`, Menüeintrag „Kantenform“ (grau ohne Naht; ADR-0023 Nachträge 6 und 7). |
| **Vollansicht** | Das ganze Original mit denselben Stauch-Streifen, ohne Zuschnitt; nur beim Werkzeug Zuschneiden gezeigt. Die Ansicht liegt darin bei `VollVersatz` (ADR-0023 Nachtrag 5). |
| **Schritt-Nummer** | Nummerierter Kreis, der beim Setzen selbst hochzählt. |
| **Stempel** | Fertiges Symbol aus einer durchsuchbaren Sammlung (Icon-Sets oder eigene). |
| **Schnellstil** | Gespeicherter Satz aus Farbe, Strichstärke, Schrift und, bei eigenen, Schatten für ein Werkzeug. Eingebaute stehen fest im Programm, eigene (höchstens 16 je Art) in `styles.ini` (ADR-0037). |
| **Sprechblase** | Text mit Spitze (`document.Text.Spitze`), kein eigenes Objekt; Werkzeug K. Ohne Füllung zwei Schenkel statt Fläche (ADR-0021 Nachtrag 13). |
| **Spitze (Sprechblase)** | Punkt im Original, auf den die Sprechblase zeigt; nicht die Pfeilspitze. |
| **Pfeil-Stil, Pfeilspitze (Kopf), Linie** | Pfeil-Stil heißt die Wahl der Spitze je Ende eines Pfeils (Anfang bei A, Ende bei B): gefülltes Dreieck, schlank, eingekerbt, offen, halb, Punkt, Raute, Quadrat, Querstrich oder keine; in Datei und Agenten-Schnittstelle `triangle`, `narrow`, `notched`, `open`, `half`, `dot`, `diamond`, `square`, `bar`, `none`. Keine an beiden Enden ist die **Linie**; sie bleibt das Objekt Pfeil (ADR-0021 Nachträge 19 und 20). |
| **Übernahme** | Eine Datei außerhalb der Ablage wird mit ihrer ersten Änderung als Aufnahme in die Bibliothek kopiert (der Editor speichert sofort, `uebernahmePruefen`); ohne Änderung kommt nichts hinein. Gleiche Inhalte führt `imports.jsonl` beim Öffnen über die SHA-256-Summe zur vorhandenen Aufnahme (ADR-0016 Nachträge 10 und 11). |
| **Datei von außen** | Eine Bilddatei außerhalb der Ablage, geöffnet über `schnapp DATEI`, „Öffnen mit“ oder Datei → Öffnen…. Sie wird nie verändert; mit der ersten Änderung entsteht eine Aufnahme (→ Übernahme). Im Code `aussen` / `ui.Geoeffnet.Aussen`. |
| **Strichart** | Englisch „Line style“: Muster des Strichs von Pfeil (Schaft), Kasten und Lupe — durchgezogen (`solid`, Voreinstellung; im Code und im ADR „voll“, `StrichVoll`), gestrichelt (`dashed`), gepunktet (`dotted`); Spitzen bleiben voll. Klappfeld unter der Strichstärke, `document.Strich.Art`, Format `s:strichart` (Version 2). Nicht „Linienstil“ und nicht mit dem Pfeil-Stil (Spitzen) verwechseln. ADR-0021 Nachtrag 25; über 16384 Stücke je Objekt voll (F-840). |
| **Schatten** | Englisch „Shadow“: Schlagschatten einer Ebene (jede Beschriftung), versetzt entgegen der Richtung des Lichts, weich, in eigener Farbe (Winkel, Länge, Weich, Farbe; `document.Ebene.Schatten`, Format `s:schatten`, Version 2). In der rechten Leiste Abschnitt „Shadow“ (Kästchen, Richtungsscheibe, Abstand, Weichheit, Farbe; `internal/ui/schattenleiste.go`), das Feld Schatten des Farbwählers (`canvas.FeldSchatten`), Schnellstile mit Schatten (`styles.ini` `shadow`), dazu `--annotate`/MCP (`shadow`). Nicht der Schatten im Spalt einer Stauch-Naht (Kantenschicht). ADR-0021 Nachtrag 26. |
| **Klappfeld** | Feld, das seinen Wert zeigt und auf Klick, Enter oder Leertaste eine Liste über die Menü-Mechanik aufklappt (Farbe und Zoom der Fußzeile, Zeitraum der Bibliothek, Pfeil-Stil Anfang/Ende, Strichart). Auch „Feld mit Liste“; nicht „Klappliste“. |
| **Einstellungstafel** | Tafel über dem Editor (Strg+,), die `settings.ini` liest und nur geänderte Schlüssel schreibt; kein eigenes Fenster (ADR-0034). |
| **Text aus dem Bild** | Texterkennung über ein installiertes `tesseract`, sonst über `schnapp-ocr`, auf dem sichtbaren Bild (nie dem Original); Ergebnis in die Zwischenablage (ADR-0035). |
| **schnapp-ocr** | Eigenes Hilfsprogramm (Modul `ocr/`): tesseract als WebAssembly mit eingebautem Deutsch und Englisch, springt ein, wenn kein `tesseract` installiert ist; langsamer, eine Sprache je Lauf (ADR-0035 Nachtrag 1). |
| **Bereichsmodus** | Einmaliger Zustand nach Strg+Umschalt+T: Ziehen wählt den Bereich der Texterkennung, das Werkzeug bleibt. |
| **Spotlight** | Alles außer einem Bereich abdunkeln. |
| **Lupe (Beschriftung)** | Vergrößerter Ausschnitt, neben die Stelle gesetzt. |
| **Blatt** | Mehrere Bilder auf einer Fläche (Vorher-nachher, Schritt-für-Schritt). |
| **Zeichenpakete** | Die aus einem Schwesterprojekt übernommenen Go-Pakete `svg`, `raster`, `geo` (ADR-0012). |
| **Wechsel** | Öffnen einer anderen Aufnahme im selben Editorfenster (Leiste der letzten Aufnahmen oder volle Ansicht der Bibliothek): erst wird die offene gespeichert wie mit Strg+S, dann die neue geladen; solange ruht das Bearbeiten. Kein Wechsel bei offenem Export, laufender Texteingabe, Zug, Arbeit der Ansicht oder laufendem Kopieren. ADR-0036, `internal/ui/wechsel.go`. Der Verlauf der verlassenen Aufnahme bleibt im Fenster gemerkt (→ Fortsetzen). |
| **Navigator** | Mini-Übersicht unten rechts auf der Leinwand, nur wenn das Bild bei dieser Zoomstufe nicht ins Fenster passt; Klicken und Ziehen verschiebt die Ansicht. Ansicht → „Navigator“. ADR-0031 Nachtrag 9, `internal/canvas/navigator.go`. |
| **Einrasten** | Englisch „snap“. Verschieben, Griffe und neue Pfeile, Kästen und Nummern rasten an Kanten und Mitten anderer sichtbarer Objekte und des Bilds ein (6 Fensterpixel), orange Hilfslinien zeigen das Ziel; Alt oder Ansicht → „An Objekten einrasten“ schaltet es ab. ADR-0021 Nachtrag 12. |
| **Farbpaar** | Die zwei Farben einer Beschriftung: Vordergrund (Strich bzw. Schrift) und Füllung, je Werkzeug gemerkt, „Keine“ möglich, Tauschen mit Strg+Umschalt+X. ADR-0021 Nachtrag 11, `internal/canvas/farbpaar.go`. Ohne Füllung zeigt die Oberfläche nur ein Feld, „keine“ ist ein Feld mit Schrägstrich (Nachtrag 23); in der rechten Leiste seit ADR-0031 Nachtrag 13 als Reiter (→ Farbreiter), „keine“ vorn in den Farbfeldern. |
| **Farbfeld** | Eigene, gepflegte Farbe der Palette unter Hex und Deckkraft in der rechten Leiste (englisch „swatch“): „+“ nimmt die aktuelle Farbe auf, Rechtsklick oder Entf entfernt; höchstens 24, gespeichert in `colors.ini`, ohne Datei die eingebauten `canvas.StandardFarbfelder`. Nicht: die zwei Felder des Farbpaars (→ Farbpaar; im Code `canvas.Farbfeld`, Kontext `color field`) und nicht die zuletzt benutzten Farben. ADR-0021 Nachtrag 24. |
| **Farbreiter** | Reiter oben im Abschnitt Farbe der rechten Leiste, je Farbfeld einer (Farbe, Füllung, Schatten) mit Farbmuster und Namen; der grün hervorgehobene ist das Ziel des Farbwählers. Im Code `zeichneFarbReiter`, Plätze `paarVorn`…`paarSchatten`. ADR-0031 Nachtrag 13. |
| **Richtungsscheibe** | Runde Scheibe im Abschnitt Schatten: Klicken oder Ziehen zum Zeiger setzt die Fallrichtung (15°-Raster, Umschalt frei), die Zahl daneben ist der Lichtwinkel. `zeichneScheibe`, `canvas.SchattenWinkelZu`. ADR-0031 Nachtrag 13. |
| **Zuletzt benutzte Farbe** | Eine der höchstens acht Farben im Raster neben der Farbfläche; füllt sich von selbst mit jeder benutzten sichtbaren Farbe, gilt je Fenster, wird nicht gespeichert (`canvas.ZuletztGrenze`). ADR-0021 Nachträge 9, 17, 24. |
| **Fortsetzen, gemerkte Aufnahme** | Beim Wechsel merkt der Editor das Dokument der verlassenen Aufnahme mit Rückgängig-Verlauf (höchstens 4, zusammen 512 MiB, nur gespeichert, ohne Schwärzung im Verlauf, mit dem Dateistand der eigenen Speicherfunktion); führt ein Wechsel zurück und trägt die Datei noch diesen Stand, wird damit fortgesetzt statt neu geladen (`ui.Anbindung.Fortsetzen`, `internal/ui/verlaufmerker.go`). ADR-0036 Zusatz Karte #356. |
| **Agenten-Aufnahme** | Aufnahme, die ein Agent über den MCP-Server (`schnapp mcp`) gemacht oder beschriftet hat; sie liegt in der Bibliothek unter `agents/`, fehlt in der Leiste der letzten Aufnahmen und erscheint in der vollen Ansicht nur mit dem Schalter. ADR-0030 (Nachträge 2 und 13). |

## Entwicklungsbegriffe

| Begriff | Bedeutung |
|---|---|
| **Sprint** | Arbeitseinheit auf dem Board (`kind:sprint`), endet mit `/sprint-abschluss`. |
| **Fassung** | Themenbündel aus den Anforderungen (erste, zweite, dritte Fassung); kein Prozessbegriff, wird in Sprints abgearbeitet. |
| **Prototyp** | Wegwerf-Programm, das entschied, ob Gio trägt (ADR-0003); in Sprint 9 entfernt, Stand in der git-Geschichte (ADR-0027). |
| **Meilenstein** | Erreichter Funktionsstand mit Version (MVP = erste Fassung). |
| **Finding** | Befund in `docs/findings.md` mit Typ, Priorität und Board-Karte. |
| **Schritt** | Eine Karte bzw. ein abgeschlossener Arbeitsgang, danach Schritt-QA. |

## Speichern im Editor

| Begriff | Bedeutung |
|---|---|
| **Abzug** | Unabhängige Kopie eines Dokuments mit gleichem Stand, ohne Rückgängig-Verlauf; wird im Hintergrund gespeichert oder kopiert, während das Bearbeiten ruht (`document`, ADR-0020 Nachtrag 6). |
| **Marke** | Meldung eines erreichten Speicherschritts (Rendern, Kodieren, Schreiben …); zählt als Fortschritt, mit `SCHNAPP_DEBUG` mit Zeitstempel (`internal/saveprogress`, ADR-0020 Nachtrag 9). |
| **Puls** | Fortschrittsmeldung aus einer langen Schleife innerhalb eines Schritts (Rastern, PNG-Kodierung, Lesen, Vorschau), damit ein langer, aber arbeitender Schritt nicht als hängend gilt. |
| **Fortschritt** | Zeitpunkt der letzten Marke oder des letzten Pulses (`saveprogress.Zuletzt`); die Frist für hängendes Speichern zählt ab ihm, frühestens ab Beginn des Speicherns. |
| **Rückfall** | Wird in Schnapp viererlei genannt: (1) in `library` der Weg über `O_EXCL`, wenn das exklusive Ablegen per Hardlink nicht geht (ADR-0016 Nachtrag 4); (2) im Export das direkte Schreiben eines vorhandenen Ziels, wenn neben ihm keine temporäre Datei entstehen darf, mit Sicherung des alten Inhalts über einen Deskriptor und `ErrZielBeschaedigt`, wenn auch das Wiederherstellen misslingt (ADR-0025 Nachträge 3 und 4); (3) in `ui` die Kopie, die das Fenster selbst hält, weil es keinen Halter gibt — beim Schließen ist das Bild dann aus der Zwischenablage weg, das Fenster warnt einmal (ADR-0024 Nachtrag 6); (4) bei einer Datei von außen hieß bis ADR-0016 Nachtrag 10 der Weg „erstes Speichern legt ab“ so; seit Nachtrag 11 ist er der Regelweg der Übernahme (von der ersten Änderung angestoßen) und Rückfall nur noch, wenn dieses Anstoßen ausbleibt (Schwärzung im Verlauf) oder scheitert (dann Strg+S oder Schließen). |
| **Rettungskopie** | Englisch „rescue copy“. Kleine JSON-Datei, die der Editor nach Änderungen im Hintergrund schreibt, damit ungespeicherte Arbeit einen Absturz, SIGKILL oder Stromausfall übersteht: Beschriftungen mit ihren Texten, Zuschnitt, Stauchstreifen und die Schwärzungen seit dem letzten Speichern, keine Pixel. Ort `$XDG_STATE_HOME/schnapp/rescue/` (ohne die Variable `~/.local/state/schnapp/rescue/`), Ordner 0700, Datei 0600, je Ausgangsdatei eine (Name aus dem SHA-256 ihres Pfads); die Kopie trägt den absoluten Pfad der bearbeiteten Datei samt Größe, Änderungszeit und SHA-256. Gelöscht nach gelungenem Speichern; beim Öffnen derselben unveränderten Datei angewendet, sonst als `….alt.json` beiseitegelegt; Beim Start des Editors fällt jede Kopie weg, deren eigene Änderungszeit mehr als 30 Tage zurückliegt, auch eine beiseitegelegte oder nie angewendete. Ein zweites Fenster auf derselben Datei sichert nicht (Sperrdatei `<SHA>.lock` im selben Ordner). `internal/rescue`, ADR-0029. |
| **Halter** | Prozess ohne Fenster (`wlclip`), der ein kopiertes Bild nach dem Schließen des Editors in der Zwischenablage hält (ADR-0024). |
| **Hängendes Speichern** | Speichern, das seit der Frist (15 s) keinen Fortschritt gemeldet hat. Nur dann gibt eine zweite Schließen-Anfrage oder ein weiteres Signal es auf; beim Zerstören des Fensters gilt zusätzlich höchstens 2 Minuten ab Beginn (ADR-0020 Nachträge 7 und 9). |
