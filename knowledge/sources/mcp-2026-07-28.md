# Model Context Protocol, Spezifikation 2026-07-28 (stdio, Werkzeuge)
- URL: https://modelcontextprotocol.io/specification/2026-07-28/ (Unterseiten: changelog, basic/index,
  basic/lifecycle, basic/transports/stdio, server/discover, server/tools; dazu docs/2026-07-28/learn/versioning)
- Abgerufen: 2026-11-22 (WebFetch über einen Sub-Agenten; Wortlaut nicht per curl gegengeprüft)
- Herausgeber / Stand: MCP-Projekt, Revision 2026-07-28 (aktuell laut Versioning-Seite)
- Verlässlichkeit: offiziell

## Kernaussagen
- **Kein Handshake mehr:** `initialize` und `notifications/initialized` sind entfallen, ebenso `ping` und
  `logging/setLevel` (changelog). Jede Anfrage trägt in `params._meta` `io.modelcontextprotocol/protocolVersion`
  (Pflicht), `io.modelcontextprotocol/clientCapabilities` (Pflicht, darf `{}` sein) und
  `io.modelcontextprotocol/clientInfo` (SHOULD); fehlt ein Pflichtfeld: JSON-RPC-Fehler `-32602` (basic/index).
- **`server/discover`** muss jeder Server können; Antwort `resultType`, `supportedVersions`, `capabilities`,
  `_meta["io.modelcontextprotocol/serverInfo"]`, optional `instructions`, `ttlMs`, `cacheScope` (server/discover).
- **Unbekannte Version:** Fehler `-32022` (früher `-32004`) mit `data.supported` und `data.requested`.
- **Zwei Epochen:** „A request carrying modern per-request `_meta` is served statelessly …; an `initialize` request
  selects legacy semantics“ (versioning). Clients proben über stdio erst mit `server/discover`, sonst `initialize`.
- **stdio:** zeilenweise JSON ohne eingebettete Zeilenumbrüche; stdout nur Protokollnachrichten, stderr für Logs;
  der Server soll bei EOF auf stdin zügig enden; Abbruch per `notifications/cancelled`.
- **Ergebnisse:** jedes Ergebnis trägt `resultType` (`"complete"`); `tools/call` liefert `content`
  (`{"type":"text","text":…}`, `{"type":"image","data":<base64>,"mimeType":"image/png"}`), `isError`, optional
  `structuredContent` (dann zusätzlich als Text). `tools/list` liefert `tools`, `ttlMs`, `cacheScope` (Pflicht seit
  dieser Revision). Werkzeug: `name`, `title`, `description`, `inputSchema` (JSON-Schema-Objekt, nie null),
  optional `outputSchema`, `annotations`. Namen 1–128 Zeichen aus `A-Za-z0-9_-.`; feste Reihenfolge.
- Unbekanntes Werkzeug: JSON-RPC-Fehler `-32602`; Ausführungsfehler: Ergebnis mit `isError: true`.

## Offene Punkte
- Batching (JSON-RPC-Arrays) auf den gelesenen Seiten nicht erwähnt — Schnapp lehnt Arrays ab.
- Felder in `annotations` (readOnlyHint usw.) nicht gelesen; Schnapp setzt keine.
- Die 2025-11-25-Seiten (Handshake) nicht gelesen; die Altform folgt dem bekannten Ablauf `initialize` →
  `notifications/initialized` → `tools/*` (⚠️ unbelegt für Einzelheiten jenseits dieser Teilmenge).
