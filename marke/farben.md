# Farben Schnapp

Stand 19.11.2026, Entwurf (Logo-Runde 2). Eine Palette für Logo **und** Oberfläche: dunkelgrauer Grund, dezentes
Grün als Hauptfarbe, dezentes Orange als Gegenfarbe. Grün und Orange sind gleich hell gewählt, damit keine der beiden
schreit; auf Grau erreichen beide mindestens 5:1.

Alle Paare erreichen WCAG AA (4,5:1) für normalen Text.

## Regeln

- Logo: höchstens Grün + Orange auf Grau (dunkel) bzw. gruen-700 + orange-700 auf Weiß (hell). Einfarbig muss es
  auch gehen.
- **Grün und Orange nie als einziges Unterscheidungsmerkmal** (gleich hell, für Rot-Grün-Schwäche schwer zu
  trennen): immer Form, Symbol oder Text dazu.
- Beschriftungsfarben im Editor (Pfeile, Kästen) sind eine eigene Auswahl für Bilder, nicht diese Palette.
